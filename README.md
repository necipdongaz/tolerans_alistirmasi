# Tolerans Alıştırması

FAA Order 8200.1D CHG 2 tolerans değerlerinden kodla üretilen alıştırma. İki soru türü var: tolerans içi/dışı kararı ve alt/üst sınır. Yapay zekâ kullanılmaz. Uygulama telefona kurulabilir (PWA) ve internetsiz çalışır.

- `index.html`: uygulama (veri içinde gömülü)
- `tolerans_verisi.json`, `tolerans_tablosu.csv`: tolerans tablosu (her satırda FAA tablo ve paragraf referansı)
- `manifest.webmanifest`, `sw.js`, ikonlar: kurulum ve internetsiz çalışma

Eğitim amaçlıdır; resmî değerlendirmede asıl belgeye bakın.
